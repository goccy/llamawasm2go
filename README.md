# llamawasm2go

Pure-Go form of [llama.cpp](https://github.com/ggml-org/llama.cpp), transpiled
from `wasm64-wasip1` by [wasm2go](https://github.com/goccy/wasm2go) via the
[llama-wasm](https://github.com/goccy/llama-wasm) pipeline. No cgo, no wasm
runtime — the inference engine runs as ordinary Go with native SIMD assembly
on arm64/amd64.

This module is generated, not hand-written: every file here is the extracted
`llama_wasm2go.tar.gz` asset of a llama-wasm release, committed verbatim so it
can be consumed as a versioned Go dependency. Do not edit it by hand; it is
replaced wholesale on each update.

## Usage

Not consumed directly. [go-llama](https://github.com/goccy/go-llama) provides
the idiomatic API and depends on this module for the engine bundle.

## Provenance

- llama.cpp: build `b10223` (commit `11924d4c`)
- Generated by the llama-wasm `v0.3.4` release pipeline (wasm2go v0.5.14, wasmify v0.6.15; the hot kernels are assembly overrides from llama-wasm `kernels/`).
